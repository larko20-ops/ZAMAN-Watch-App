# ZAMAN Watch Store

ئەم پڕۆژەیەی Flutter بۆ ئەپی فرۆشتنی سەعاتی ZAMAN ـە و بۆ Android و iOS دروست کراوە.

## پێویستییەکان
- Flutter SDK
- Android Studio بۆ Android
- Xcode بۆ iOS (لە macOS)

## ڕاکردن
```bash
flutter pub get
flutter run
```

## Android APK
```bash
flutter build apk --release
```

## iOS
لە macOS:
```bash
flutter build ios --release
```

بۆ بڵاوکردنەوە لە App Store و Google Play، پڕۆسەی signing، developer account و store metadata پێویستە.
